О работе инструмента

Сохранение структуры: при включённой опции текст извлекается с учётом расположения строк и абзацев. Для PDF с текстовым слоем используются координаты элементов; для сканов — данные Tesseract о блоках и строках.

Приватность: вся обработка происходит в вашем браузере. Файлы не загружаются на сервер.

Качество: чем чётче исходное изображение, тем лучше результат. Для бумажных анализов делайте фото при хорошем освещении, без бликов.
